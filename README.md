# 🎓 Student Hub

Student Hub is a web-based Academic Management Portal that allows students to access their academic information from a single platform.

## 📌 Features
- Student Login
- Dashboard
- Profile
- Attendance
- Timetable
- Assignments
- Results
- Announcements
- Events
- Fees
- Feedback

## 🛠 Technologies Used
- HTML5
- CSS3

## 🚀 How to Run
1. Open the project folder.
2. Open `index.html` in your browser or Live Server.
